Product Electrical Properties is an Odoo module designed for managing electronic components and their electrical specifications. It seamlessly integrates with the Nexar-Octopart API to provide automatic retrieval of component specifications and detailed electrical characteristics.

Key Features
============

* Component electrical specifications management
* Nexar-Octopart API integration for automatic data retrieval
* Advanced reel packaging management system
* Support for manufacturer-specific packaging definitions
* Dynamic component property definitions through XML
* Automated MPN-based specification updates

Configuration
=============

API Configuration
=================

1. Go to Settings > Users
2. Select the user who will use the Nexar API
3. Configure:
   * Nexar Client ID
   * Nexar Client Secret

Component Definitions
=====================

1. Edit `data/component_definition.xml`
2. Define component properties:
   * Electrical characteristics
   * Measurement units
   * Validation rules
3. Restart Odoo server to apply changes

Usage
=====

Component Management
====================

To manage electrical components:

1. Go to Inventory > Products
2. Create or select a product
3. Set the component type
4. Fill in electrical specifications manually or use automatic retrieval

Nexar Integration
=================

To update component data from Nexar:

1. Open a product form
2. Click "Update from Nexar"
3. Verify and save the retrieved specifications

Packaging Management
====================

To manage reel packaging:

1. Go to Inventory > Configuration > Packaging
2. Create new reel packaging type
3. Set dimensions (diameter, width, length)
4. Define quantity per package
