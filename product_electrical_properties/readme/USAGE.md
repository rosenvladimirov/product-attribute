## Usage Guide

### Configuring Nextar Integration
1. Enter Nextar credentials in user settings
2. Verify API connection

### Managing Electrical Characteristics
1. Open product
2. Select component type
3. Fill in electrical characteristics
4. Use "Update from Nextar" button for automatic population

### Working with Reel Packaging
1. Create new packaging type
2. Set dimensions (diameter, width, length)
3. Link to manufacturer
4. Define component quantity

### Adding New Component Definitions
1. Edit `component_definition.xml`
2. Add new properties
3. Restart server
