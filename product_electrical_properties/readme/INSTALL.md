## Installation Guide

### Prerequisites
- Odoo 18.0
- Python 3.11+
- Nextar API access

### Installation Steps
1. Clone repository to `addons` directory:
   ```bash
   git clone [repo-url] /path/to/odoo/addons/
   ```

2. Install dependencies:
   - product
   - base
   - mrp
   - purchase
   - product_manufacturer
   - product_manufacturer_data

3. Update module list in Odoo

4. Install "Product Electrical Properties" module
