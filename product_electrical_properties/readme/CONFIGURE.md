## Product Electrical Properties Configuration

### Requirements
- Odoo 18.0 installed
- Required modules installed:
  - product
  - base
  - mrp
  - purchase
  - product_manufacturer
  - product_manufacturer_data

### Nexar API Configuration
1. Go to Settings -> Users
2. Select user
3. Enter:
   - Nexar Client ID
   - Nexar Client Secret
4. Save settings

### Component Definitions
1. Create or edit `data/component_definition.xml`
2. Define electrical properties in XML format
3. Restart application to apply changes
