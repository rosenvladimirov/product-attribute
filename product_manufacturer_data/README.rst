This module extends Odoo's product management by adding comprehensive manufacturer information handling capabilities.

Context
=======

This module is developed to:

* Manage product manufacturer information
* Link products with their manufacturers
* Track manufacturer-specific product information:

  * Manufacturer's product name
  * Manufacturer's product code
  * Product URL on manufacturer's website

* Integrate with supplier information

Installation
============

To install this module, you need to:

#. Navigate to Apps menu in Odoo
#. Remove the Apps filter/condition
#. Search for "Product Manufacturer Data"
#. Click Install button

Dependencies will be automatically installed:

* Product
* Product Brand
* Product Manufacturer

Configuration
============

To configure this module, you need to:

#. Go to Settings > Technical > Users & Companies > Users
#. Set up access rights for:

   * Creating manufacturers
   * Viewing manufacturers
   * Editing manufacturer information

#. In Inventory > Configuration > Product Categories verify that product categories are properly set up

Usage
=====

To use this module, you need to:

#. Adding a Manufacturer to a Product:

   * Open a product
   * Go to the "Manufacturers" tab
   * Click "Add a line"
   * Fill in:

     - Manufacturer
     - Manufacturer Product Name
     - Manufacturer Code
     - Product URL

#. Linking a Supplier with Manufacturer:

   * Open product supplier information
   * Select the corresponding manufacturer information
   * System will automatically link the information

#. Searching Products by Manufacturer:

   * Use filters in the products view
   * Search by manufacturer name or manufacturer code
