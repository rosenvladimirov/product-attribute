# Configuration

To configure the "Product Manufacturer Data" module:

1. Go to Settings > Technical > Users & Companies > Users
2. Set up access rights for:
   - Creating manufacturers
   - Viewing manufacturers
   - Editing manufacturer information
3. In Inventory > Configuration > Product Categories verify that product categories are properly set up

Note: This module requires `product`, `product_brand`, and `product_manufacturer` modules to be installed.
