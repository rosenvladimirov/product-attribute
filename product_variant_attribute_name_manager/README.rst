This module allows you to manage how to display the attributes on the product variant name.

**Features:**

* Choose if you want to display the name of the attribute before its value
* Choose if you want to display the attribute value in the product name
* Set a short name to be displayed as the attribute's name
* Set the order of the attributes for each product
* Choose if you want to display attribute value name for Single Variant Attribute

Configuration
=============

To configure this module:

1. Go to **Sales > Configuration > Product Categories & Attributes > Attributes**
2. Edit an attribute and set a **Short Name** if you want to use a shorter version in variant names
3. Edit attribute values and uncheck **Show in Variant Name** if you don't want a specific value to appear in variant names

Usage
=====

To use this module:

1. Go to a product template with variants
2. In the **Variants** tab, you can configure:

   * **Display Variant Name with Attributes**: Enable/disable attribute display in variant names globally for this product
   * **Display Attribute Name**: Show attribute names before values (e.g., "Color: Red" instead of just "Red")

3. For each attribute line, you can configure:

   * **Sequence**: Order in which attributes appear in the variant name
   * **Display Attribute Name**: Override the global setting for this specific attribute
   * **Display Attribute Values**: Show/hide this attribute's values in variant names

**Example:**

Product: T-Shirt
Attributes:
- Color: Red (display: yes), Blue (display: yes)
- Size: S, M, L (all display: yes)

Configuration:
- Display Attribute Name: Yes
- Attribute line sequence: Color (10), Size (20)

Result: "T-Shirt (Color: Red, Size: M)"
